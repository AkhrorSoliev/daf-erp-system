Compact button for a single icon — card "open" arrows, header actions, close buttons.

```jsx
<IconButton variant="white" ariaLabel="Open"><i className="ph-bold ph-arrow-up-right" /></IconButton>
<IconButton variant="primary" size="lg"><i className="ph-fill ph-house" /></IconButton>
```

Variants: `primary | soft | white | teal | ghost`. `shape="circle"` (default) or `"squircle"`. Pass the icon as children.
