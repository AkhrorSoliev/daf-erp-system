Chunky rounded clay button — the primary tap action across Lumio. Presses physically down on tap (the bottom lip collapses).

```jsx
<Button variant="primary" size="lg" block onClick={start}>Ha, qaytish</Button>
<Button variant="secondary" iconBefore={<i className="ph-bold ph-play" />}>Davom etish</Button>
<Button variant="amber" size="sm">+10 XP</Button>
```

Variants: `primary` (coral), `secondary` (white), `ghost`, `amber`, `teal`. Sizes: `sm | md | lg`. Use `block` for full-width CTAs, `iconBefore`/`iconAfter` for icons.
