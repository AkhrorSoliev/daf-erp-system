Floating glass pill tab bar. The active tab becomes a solid coral circle (icon only); inactive tabs show icon + label.

```jsx
<BottomNav value={tab} onChange={setTab} items={[
  { value:'home', label:'Asosiy', icon:<i className="ph ph-house"/>, iconActive:<i className="ph-fill ph-house"/> },
  { value:'lessons', label:'Darslar', icon:<i className="ph ph-path"/> },
]} />
```
