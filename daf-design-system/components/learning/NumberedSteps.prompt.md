Numbered onboarding path — chunky clay numbered tiles alternating left/right, joined by dashed connectors, each with an explanatory bubble. Use for empty states ("Sizda hali so‘zlar yo‘q") and how-it-works intros.

```jsx
<NumberedSteps tone="grape" steps={[
  'Darslikdan yangi so‘zlar qo‘shing — ular shu yerda saqlanadi.',
  '“O‘rganilayotgan so‘zlar” bo‘limida saqlanadi.',
  'To‘liq o‘zlashtirilganda “Hamma so‘zlar”ga o‘tadi.',
]} />
```
