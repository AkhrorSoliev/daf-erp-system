White capsule pairing an icon + number for gamification stats in headers.

```jsx
<StatChip kind="xp" icon={<i className="ph-fill ph-lightning" />} value="201" />
<StatChip kind="coin" icon={<i className="ph-fill ph-coin" />} value="0" />
```

`kind`: xp | coin | streak | gem | neutral (sets icon color).
