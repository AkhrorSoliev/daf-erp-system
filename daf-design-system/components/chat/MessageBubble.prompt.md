Chat message bubble — coral & right for the current user, white & left for others.

```jsx
<MessageBubble side="them" name="Asror" time="10:14">Salom! Bugun mashq qilamizmi?</MessageBubble>
<MessageBubble side="me" time="10:15">Albatta 💪</MessageBubble>
```

Use `name` only for incoming group messages; `tail` draws the pointed corner.
