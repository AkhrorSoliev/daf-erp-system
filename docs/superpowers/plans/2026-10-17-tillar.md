# Languages (uz, uz-Cyrl, ru, de, en) — Mechanism and Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the admin/teacher portals five interface languages (O'zbekcha, Ўзбекча, Русский, Deutsch, English) chosen per account and per device, with the app shell (sidebar, header, user menu, breadcrumb, notification bell) fully translated.

**Architecture:** The Uzbek-Latin source text is the translation key (`t("Bosh sahifa")`). `ru`/`de`/`en` have dictionary files (source → translation); Uzbek Cyrillic is derived from the source by a rule-based transliterator; a missing translation shows the Uzbek source. The dashboard server layout reads the `daf-locale` cookie, loads that language's dictionary and hands both to a client `I18nProvider` (no flash of Uzbek). The language is also stored on the account (`User.uiLocale`, `PATCH /users/ui-locale`). A test (`npm run i18n:check`) proves every text of the shell files exists in all three dictionaries.

**Tech Stack:** NestJS + Prisma + Jest (`server/`), Next.js 16 + React 19 + zustand + vitest (`client/`).

**Spec:** `docs/superpowers/specs/2026-10-17-tillar-design.md` (two amendments, made in Task 7: only `msg()` needs a literal argument — `t(item.title)` of a `msg` value is legal; the dictionaries for `uz-Cyrl` are optional overrides). The login page is NOT in this plan: `feat/kirish-logotip-varaqlari` is not on `main` yet and rewrites the login files; a separate plan translates login after it lands.

## Global Constraints

- Locale ids, in this order: `uz` (default), `uz-Cyrl`, `ru`, `de`, `en`; labels in their own language: «O'zbekcha», «Ўзбекча», «Русский», «Deutsch», «English». Unknown/missing → `uz`.
- Cookie: `daf-locale`, `path=/`, `max-age=31536000`, `SameSite=Lax`, readable by JS and by the server. Account column: `User.uiLocale String?` (null = `uz`).
- `msg()` takes a string LITERAL and returns it unchanged (a marker for the coverage test). `t(x)` may take a variable that came from `msg()`.
- Numbers, dates and times keep their formats in every language (`1 500 000`, `dd.MM.yyyy`). Server-sent text (error messages, notification titles and bodies, PDF, Excel, Telegram, SMS) is never translated here.
- Dictionaries: `client/src/i18n/dictionaries/{ru,de,en}.ts`, `Record<string,string>` source → translation, identical key sets in the three files. A placeholder `{name}` in a key must appear unchanged in every translation. `uz-cyrl.ts` holds only overrides for words the transliterator gets wrong.
- Translation style: menu/label text capitalized like the source, sentences in sentence case, same ending punctuation as the source, no emoji added or removed. German nouns capitalized. Keep sidebar and button labels short (a longer translation than 1.5× the source needs a shorter word).
- Glossary (use exactly these for every task): Bosh sahifa = Главная / Startseite / Home; Jadval = Расписание / Stundenplan / Schedule; O'quvchilar = Ученики / Teilnehmer / Students; O'qituvchilar = Преподаватели / Lehrkräfte / Teachers; Guruhlar = Группы / Gruppen / Groups; Kurslar = Курсы / Kurse / Courses; Xonalar = Аудитории / Räume / Rooms; Lidlar = Лиды / Leads / Leads; Aloqa markazi = Колл-центр / Kontaktzentrum / Contact center; Topshiriqlar = Задачи / Aufgaben / Tasks; Topshiriq = Задача / Aufgabe / Task; Moliya = Финансы / Finanzen / Finance; To'lovlar = Платежи / Zahlungen / Payments; Xarajatlar = Расходы / Ausgaben / Expenses; Ish haqi = Зарплата / Gehalt / Salary; Qarzdorlik = Задолженность / Schulden / Debt; Hisobotlar = Отчёты / Berichte / Reports; Sozlamalar = Настройки / Einstellungen / Settings; Qo'llanma = Руководство / Anleitung / User guide; Bildirishnoma = Уведомление / Benachrichtigung / Notification; Filial = Филиал / Filiale / Branch; Barcha filiallar = Все филиалы / Alle Filialen / All branches; Davomat = Посещаемость / Anwesenheit / Attendance; Dars = Занятие / Unterricht / Lesson; Profil = Профиль / Profil / Profile; Chiqish = Выйти / Abmelden / Sign out; Ko'rinish = Вид / Darstellung / Appearance; Dizayn uslubi = Стиль оформления / Designstil / Design style; Til = Язык / Sprache / Language; Yorug' = Светлая / Hell / Light; Qorong'i = Тёмная / Dunkel / Dark; Tizim = Системная / System / System; Texnik yordam = Техподдержка / Technischer Support / Technical support; Mock imtihonlar = Пробные экзамены / Probeprüfungen / Mock exams; so'm = сум / Sum / UZS. import { describe, expect, it } from "vitest";
```ts
import { interpolate, translate } from "./translate";

const ru = { "Bosh sahifa": "Главная", "{n} ta o'quvchi": "{n} учеников" };

describe("interpolate", () => {
  it("fills {name} placeholders and leaves unknown ones", () => {
    expect(interpolate("{n} ta o'quvchi", { n: 5 })).toBe("5 ta o'quvchi");
    expect(interpolate("{a} va {b}", { a: "x" })).toBe("x va {b}");
    expect(interpolate("oddiy matn")).toBe("oddiy matn");
  });
});

describe("translate", () => {
  it("returns the Uzbek source for uz, whatever the dictionary holds", () => {
    expect(translate("uz", ru, "Bosh sahifa")).toBe("Bosh sahifa");
  });

  it("takes the translation from the dictionary for ru, de and en", () => {
    expect(translate("ru", ru, "Bosh sahifa")).toBe("Главная");
    expect(translate("ru", ru, "{n} ta o'quvchi", { n: 3 })).toBe("3 учеников");
  });

  it("shows the Uzbek source when there is no translation", () => {
    expect(translate("ru", ru, "Hali tarjima qilinmagan")).toBe("Hali tarjima qilinmagan");
    expect(translate("de", {}, "Jadval")).toBe("Jadval");

  it("transliterates the source for uz-Cyrl, an override in the dictionary wins", () => {
```

```ts
import { toCyrillic } from "./translit-cyrl";
import type { UiLocale } from "./locales";

/** Uzbek source text → text in the dictionary's language. */
export type Dictionary = Readonly<Record<string, string>>;

export type Params = Record<string, string | number>;

/** Fills `{name}` placeholders from `params`; an unknown placeholder stays as written. */
export function interpolate(text: string, params?: Params): string {
  if (!params) return text;
  return text.replace(/\{(\w+)\}/g, (whole, name: string) => (name in params ? String(params[name]) : whole));
}

/**
 * The text for `source` in `locale`. Uzbek is the source itself; Uzbek Cyrillic
 * is derived from it unless the dictionary holds an override; ru, de and en read
 * their dictionary. A missing translation shows the Uzbek source, so a page that
 * is not translated yet still works.
 */
export function translate(locale: UiLocale, dictionary: Dictionary, source: string, params?: Params): string {
  let text: string;
  if (locale === "uz") text = source;
  else if (locale === "uz-Cyrl") text = dictionary[source] ?? toCyrillic(source);
  else text = dictionary[source] ?? source;
  return interpolate(text, params);
}
```

`i18n/translit-cyrl.ts`:

```ts
/**
 * Uzbek Latin → Uzbek Cyrillic (the 1995 alphabet), by rule. Good enough for
 * interface text; a word it gets wrong goes into `dictionaries/uz-cyrl.ts`.
 */

const APOSTROPHES = "'ʻʼ‘’`";
const VOWELS = "aeiou";

/** Brand and product words that Uzbek Cyrillic text leaves in Latin (compared in lower case). */
export const KEEP_LATIN: ReadonlySet<string> = new Set([
  "excel",
  "telegram",
  "payme",
  "click",
  "uzum",
  "instagram",
  "google",
  "mock",
  "daftar",
  "daf",
  "sprachzentrum",
]);

const LETTERS: Record<string, string> = {
  a: "а", b: "б", c: "к", d: "д", f: "ф", g: "г", h: "ҳ", i: "и", j: "ж", k: "к", l: "л", m: "м",
  n: "н", o: "о", p: "п", q: "қ", r: "р", s: "с", t: "т", u: "у", v: "в", w: "в", x: "х", y: "й", z: "з",
};

const isApostrophe = (c: string | undefined) => c !== undefined && APOSTROPHES.includes(c);

/** Is the letter before position `i` a vowel? An o followed by an apostrophe is ў, a vowel. */
function prevIsVowel(word: string, lower: string, i: number): boolean {
  if (i === 0) return false;
  if (isApostrophe(word[i - 1])) return i >= 2 && lower[i - 2] === "o";
  return VOWELS.includes(lower[i - 1]);
}

function convertWord(word: string): string {
  const lower = word.toLowerCase();
  let out = "";
  for (let i = 0; i < word.length; ) {
    const lc = lower[i];
    const upper = word[i] !== lc;
    const next = lower[i + 1];
    const put = (cyrillic: string) => (upper ? cyrillic.toUpperCase() : cyrillic);

    if ((lc === "o" || lc === "g") && isApostrophe(word[i + 1])) {
      out += put(lc === "o" ? "ў" : "ғ");
      i += 2;
    } else if (lc === "s" && next === "h") {
      out += put("ш");
      i += 2;
    } else if (lc === "c" && next === "h") {
      out += put("ч");
      i += 2;
    } else if (lc === "t" && next === "s") {
      out += put("ц");
      i += 2;
    } else if (lc === "y" && next !== undefined && "aoue".includes(next) && !prevIsVowel(word, lower, i) && !(next === "o" && isApostrophe(word[i + 2]))) {
      out += put({ a: "я", o: "ё", u: "ю", e: "е" }[next] as string);
      i += 2;
    } else if (lc === "e") {
      out += put(i === 0 || prevIsVowel(word, lower, i) ? "э" : "е");
      i += 1;
    } else if (isApostrophe(word[i])) {
      out += "ъ";
      i += 1;
    } else {
      const mapped = LETTERS[lc];
      out += mapped ? put(mapped) : word[i];
      i += 1;
    }
  }
  return out;
}

function convertToken(token: string): string {
  const [, lead = "", core = "", trail = ""] = token.match(/^([’'ʻʼ‘`]*)(.*?)([’'ʻʼ‘`]*)$/) ?? [];
  if (core === "") return token;
  if (/^[A-Z]{2,}$/.test(core) || KEEP_LATIN.has(core.toLowerCase())) return token;
  return lead + convertWord(core) + trail;
}

// Order matters: a placeholder, a url, an e-mail and a handle are matched before a word.
const TOKEN = /(\{[^}]*\}|https?:\/\/\S+|[\w.+-]+@[\w-]+\.[\w.-]+|@\w+|[A-Za-z’'ʻʼ‘`]+)/g;

export function toCyrillic(latin: string): string {
  return latin.replace(TOKEN, (token) => {
    if (/^[{@]|^https?:\/\//.test(token) || token.includes("@")) return token;
    return convertToken(token);
  });
}
```

`i18n/change-ui-locale.ts`:

```ts
import type { UiLocale } from "./locales";
import type { Dictionary } from "./translate";

export interface LocaleState {
  locale: UiLocale;
  dictionary: Dictionary;
}

export interface ChangeUiLocaleDeps {
  /** What the page holds now. */
  current(): LocaleState;
  /** The new language's dictionary. */
  load(locale: UiLocale): Promise<Dictionary>;
  /** Put a language into the page and the device cookie. */
  apply(locale: UiLocale, dictionary: Dictionary): void;
  /** Save it on the account (a no-op when nobody is signed in or the change came from the account). */
  persist(locale: UiLocale): Promise<void>;
  /** Tell the user which step failed. */
  fail(error: unknown, stage: "load" | "save"): void;
}

let latest = 0;

/**
 * Switch the interface language: load the dictionary, apply it at once, then
 * save it. A failed load changes nothing; a failed save puts the previous
 * language back. Only the latest call acts, so two quick choices never leave
 * the page on the older one.
 */
export async function changeUiLocale(next: UiLocale, deps: ChangeUiLocaleDeps): Promise<boolean> {
  const seq = ++latest;
  const previous = deps.current();

  let dictionary: Dictionary;
  try {
    dictionary = await deps.load(next);
  } catch (error) {
    if (seq === latest) deps.fail(error, "load");
    return false;
  }
  if (seq !== latest) return false;

  deps.apply(next, dictionary);
  try {
    await deps.persist(next);
    return true;
  } catch (error) {
    if (seq === latest) deps.apply(previous.locale, previous.dictionary);
    deps.fail(error, "save");
    return false;
  }
}
```

`i18n/locale-sync-rule.ts`:

```ts
import { DEFAULT_LOCALE, isUiLocale, type UiLocale } from "./locales";

export type LocaleSyncAction =
  | { kind: "none" }
  | { kind: "adopt-account"; locale: UiLocale }
  | { kind: "save-device"; locale: UiLocale };

/**
 * What to do once a signed-in user's language is known: the account wins over
 * the device (a language chosen on another device follows the person here); an
 * account that never chose one takes the device's language once, unless that is
 * just the default.
 */
export function localeSyncAction(input: {
  accountLocale: string | null | undefined;
  deviceLocale: UiLocale;
}): LocaleSyncAction {
  const { accountLocale, deviceLocale } = input;
  if (isUiLocale(accountLocale)) {
    return accountLocale === deviceLocale ? { kind: "none" } : { kind: "adopt-account", locale: accountLocale };
  }
  return deviceLocale === DEFAULT_LOCALE ? { kind: "none" } : { kind: "save-device", locale: deviceLocale };
}
```

```tsx
 * is already in the right language. `setLocale` switches without a reload.
 */
export function I18nProvider({
  initialLocale,
  initialDictionary,
  children,
}: {
  initialLocale: UiLocale;
  initialDictionary: Dictionary;
  children: ReactNode;
}) {
  const [state, setState] = useState<LocaleState>({ locale: initialLocale, dictionary: initialDictionary });
  const stateRef = useRef(state);

  useEffect(() => {
    stateRef.current = state;
    document.documentElement.lang = state.locale;
  }, [state]);

  const setLocale = useCallback(
    (next: UiLocale, options?: SetLocaleOptions) =>
      changeUiLocale(next, {
        current: () => stateRef.current,
        load: loadDictionary,
        apply: (locale, dictionary) => {
          stateRef.current = { locale, dictionary };
          setState({ locale, dictionary });
          writeLocaleCookie(locale);
        },
        persist: async (locale) => {
          if (options?.save === false) return;
          const { user, patchUser } = useAuth.getState();
          if (!user) return;
          await api.patch("/users/ui-locale", { locale });
          patchUser({ uiLocale: locale });
        },
        fail: (error, stage) =>
          toast.error(
            stage === "load"
              ? "Tilni yuklab bo'lmadi"
              : getErrorMessage(error, "Tilni saqlab bo'lmadi"),
          ),
      }),
    [],
  );

  const value = useMemo(() => ({ ...state, setLocale }), [state, setLocale]);
  return <I18nContext.Provider value={value}>{children}</I18nContext.Provider>;
}

/** `t("Uzbek text", { n: 5 })` in the page's language; the Uzbek text when it has no translation. */
export function useT(): (source: string, params?: Params) => string {
  const { locale, dictionary } = useContext(I18nContext);
  return useCallback((source: string, params?: Params) => translate(locale, dictionary, source, params), [locale, dictionary]);
}

export function useLocale(): { locale: UiLocale; setLocale: I18nValue["setLocale"] } {
  const { locale, setLocale } = useContext(I18nContext);
  return { locale, setLocale };
}
```

```tsx
"use client";

import { useEffect, useRef } from "react";
import { useAuth } from "@/hooks/use-auth";
import { useLocale } from "./context";
import { localeSyncAction } from "./locale-sync-rule";

/**
 * Brings the page's language in line with the signed-in account (see
 * `localeSyncAction`). Runs once per account value, so a failed save does not
 * loop.
 */
export function LocaleSync() {
  const signedIn = useAuth((s) => s.user !== null);
  const accountLocale = useAuth((s) => s.user?.uiLocale);
  const { locale, setLocale } = useLocale();
  const handled = useRef<string | null>(null);

  useEffect(() => {
    if (!signedIn) return;
    const key = `${accountLocale ?? "none"}|${locale}`;
    if (handled.current === key) return;
    handled.current = key;
    const action = localeSyncAction({ accountLocale, deviceLocale: locale });
    if (action.kind === "adopt-account") void setLocale(action.locale, { save: false });
    else if (action.kind === "save-device") void setLocale(action.locale);
  }, [signedIn, accountLocale, locale, setLocale]);

  return null;
}
```
