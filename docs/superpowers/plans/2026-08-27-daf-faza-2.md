# DaF Faza 2 — kontent bazaga va o'quvchi ekraniga

> **Ishlovchi agent uchun:** bu reja vazifama-vazifa bajariladi. Har vazifa
> o'z test siklida tugaydi va o'z commit'i bilan yopiladi.

**Maqsad:** `dib.json` dagi kontentni bazaga tushirish, o'zbekchaga o'girish,
o'quvchi portalida ko'rsatish va bitta mashq turini (MC) to'liq ishlaydigan
qilish.

**Arxitektura:** `Daf*` Prisma modellari (kontentda `companyId` yo'q,
urinishda filial muhrlanadi) → idempotent seed → `student-portal`
naqshidagi API → Lumio uslubidagi `/portal/lernen` ekrani.

**Texnologiya:** NestJS, Prisma, PostgreSQL, Next.js, React Query, Lumio
komponentlari.

**Spec:** [2026-08-27-daf-faza-2-design.md](../specs/2026-08-27-daf-faza-2-design.md)

## Umumiy cheklovlar

Bular har vazifaga tegishli — har birida qayta yozilmaydi.

- **Kontent jadvallarida `companyId` YO'Q** (D3). `DafAttempt` da bor.
- **`DafAttempt` da `branchId` va `groupId` yozish paytida muhrlanadi** —
  jonli bog'lanishdan o'qilmaydi (D3).
- **Progress jadvali yaratilmaydi** (D4). «Bajarildi» urinishlardan
  hisoblanadi.
- **To'g'ri javob mijozga yuborilmaydi.** Tekshiruv serverda (D-API).
- **Migratsiya `prisma migrate dev` bilan yaratilmaydi** — bu loyihada u
  buzilgan. `prisma migrate diff` + `db execute` + `resolve` ishlatiladi
  (xotira: prisma-migration-workflow).
- **Har o'zgarishdan keyin `npm test` va `npm run typecheck`** — ikkalasi
  ham, chunki `ts-jest` transpile-only ishlaydi va tiplarni tekshirmaydi.
- **Lint darvozasi CI bilan bir xil:** `npx eslint src` — `--fix` SIZ.
  Faza 1b da `--fix` bilan chaqirilgani 88 ta xatoni yashirgan va CI ni
  yiqitgan.
- **Uzbek matnlar faqat lotin alifbosida.**

```prisma
enum DafLevel {
  A1_1
  A1_2
  A2_1
  A2_2
  B1
}

enum DafExerciseKind {
  GAP
  MC
  CLOZE
  REORDER
  FREE_WRITE
}

/// `OPEN` — manba javob bermagan (to'g'ri javob bitta emas). Bunday mashq
/// ko'rsatiladi, lekin avtomatik tekshirilmaydi.
enum DafAnswerStatus {
  FROM_SOURCE
  PARTIAL
  OPEN
}

enum DafTranslationSource {
  MODEL
  TEACHER
}

/// O'quv yo'lining bosqichi. Manba bobi unga BIRIKTIRILADI — bo'lim
/// manbadan kelib chiqmaydi (ADR-0011).
model DafUnit {
  id            Int       @id @default(autoincrement())
  level         DafLevel
  order         Int
  titleUz       String
  titleDe       String
  /// Manbadagi bob raqami — kelib chiqishi, o'zligi emas.
  sourceChapter Int?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  lexemes   DafLexeme[]
  grammar   DafGrammar[]
  exercises DafExercise[]

  @@unique([level, order])
  @@index([level])
}

model DafLexeme {
  id                Int                   @id @default(autoincrement())
  /// Manbadagi barqaror id — seed shu bo'yicha yangilaydi.
  sourceId          String                @unique
  unitId            Int
  de                String
  en                String
  uz                String?
  translationSource DafTranslationSource?
  /// R2 kaliti, to'liq manzil emas (D7).
  audioKey          String?
  imageKey          String?
  sectionTitleDe    String
  sectionTitleUz    String?
  order             Int

  unit DafUnit @relation(fields: [unitId], references: [id])

  @@index([unitId])
}

model DafGrammar {
  id                Int                   @id @default(autoincrement())
  sourceId          String                @unique
  unitId            Int?
  code              String
  titleDe           String
  titleUz           String?
  explanationEn     String
  explanationUz     String?
  translationSource DafTranslationSource?
  level             DafLevel?

  unit      DafUnit?      @relation(fields: [unitId], references: [id])
  exercises DafExercise[]

  @@index([unitId])
}

model DafExercise {
  id            Int             @id @default(autoincrement())
  sourceId      String          @unique
  unitId        Int?
  grammarId     Int?
  kind          DafExerciseKind
  prompt        String
  /// MC variantlari. Boshqa turlarda bo'sh.
  options       String[]
  /// Har javob o'rniga bittadan. `null` element — manba javob bermagan.
  answers       Json
  answerStatus  DafAnswerStatus
  /// Manbadagi javob o'rinlari raqamlari.
  slots         Int[]
  sourceSetCode String
  order         Int
  /// Manbadan yo'qolgan mashq O'CHIRILMAYDI — belgilanadi. O'chirilgan
  /// mashqqa ishora qiluvchi urinish tarixi ma'nosini yo'qotadi.
  retiredAt     DateTime?

  unit     DafUnit?     @relation(fields: [unitId], references: [id])
  grammar  DafGrammar?  @relation(fields: [grammarId], references: [id])
  attempts DafAttempt[]

  @@index([unitId])
  @@index([grammarId])
}

/// O'zgarmas hodisa. Tahrirlanmaydi, o'chirilmaydi (D4).
model DafAttempt {
  id         Int      @id @default(autoincrement())
  studentId  Int
  exerciseId Int
  isCorrect  Boolean
  /// O'quvchi bergan javob — xato javoblar ham saqlanadi.
  given      Json
  durationMs Int?
  /// Yozish paytida MUHRLANADI, jonli bog'lanishdan o'qilmaydi (D3).
  companyId  Int
  branchId   Int?
  groupId    Int?
  createdAt  DateTime @default(now())

  student  Student     @relation(fields: [studentId], references: [id])
  exercise DafExercise @relation(fields: [exerciseId], references: [id])

  @@index([studentId, createdAt])
  @@index([exerciseId])
  @@index([companyId, createdAt])
  @@index([branchId, createdAt])
}
```

`Student` modeliga `dafAttempts DafAttempt[]` teskari bog'lanishi qo'shiladi.
